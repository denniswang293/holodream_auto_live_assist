## 目前能提出的第一失敗階段

只能對程式觀測做階段性描述，不能把它提升為實體音符根因：

1. 497 幀只知道 acquired 與 processed 的差額；因沒有獨立 capture 原始幀，實體音符狀態是 `CAPTURE_NOT_PROCESSED` 或 `SOURCE_UNKNOWN`，不能二選一。
2. 19,231 個候選 rejection 可追溯至 Detector，但沒有人工畫面標註，不能判定其中有多少是真音符。
3. `track_expired_max_gap`、`track_not_current_confirmed`、`eta_outside_horizon` 等是後續程式症狀；沒有 physical link 時不得重複計為漏按根因。

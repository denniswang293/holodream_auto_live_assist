## 3. 結論

**決定：`NEED_SHORT_LIVE_SAMPLE`。**

三個案例有中等信心的可見音符連結，且 B 在受控 fixture 能產生一個合法、及時、非重複的 Mock 動作；但缺少實體音符 ID／遊戲判定與歷史 scheduler 狀態，尚不能 Active 化或宣稱命中改善。

下一步只需要一段新的短 run（低密度、包含一般 Tap／相鄰同鍵／Hold 交錯），維持 Legacy Active；Shadow 只做單一 posterior-width B 計算、不送 B 的鍵，並額外保存必要的 scheduler/assignment/conflict 快照。若新 run 無法再次證明 B 的合法新增決策，立即 `STOP_GATE_EXPERIMENT`。

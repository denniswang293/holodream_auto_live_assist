# V7.14.10 P0 baseline

本基線是 V7.14.8 source-first 路徑的可稽核快照，不宣稱遊戲命中改善。

## Active 資料流

`src/live.py` 解析 profile 與可選 legacy override → `src/assist_config.py::resolve_config` 驗證安全範圍 → `LiveEngine` 建立幾何、Detector、Hold、Legacy tracker 與 Simple Tap core → `SimpleAssistCore` 以 `SimpleTracker` 維持 Tap 空間身份、`ParticlePredictor` 只做空間追蹤、`GlobalTapTimingEstimator` 產生唯一 Tap ETA → `TapPlanner` 做合法鍵/衝突/確認 gate → `TapIntentManager` 持有 deadline 與 amendment policy → `TapScheduler` 在 Arm/focus/ROI/stale/合法鍵條件下送鍵。

`config.json` / `config/live_assist.json` 只在明確 `--config` / `--live-config` 時作 legacy override；日常 source-first 啟動不依賴它們。幾何仍由外部 calibration 檔供應。

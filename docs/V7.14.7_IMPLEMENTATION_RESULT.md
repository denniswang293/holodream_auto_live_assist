## A/B configs and commands

Generated by `tools/prepare_v7147_ab.py`:

- `output/analysis_v7147/ab_configs/baseline_60ms_no_earlier.json`
- `output/analysis_v7147/ab_configs/experiment_60ms_earlier.json`

Only `allow_earlier_amend` differs. Each run records `experiment_id`,

Run baseline A:

```powershell
python -m src.live --config config.json --live-config output/analysis_v7147/ab_configs/baseline_60ms_no_earlier.json --geometry config/geometry_live_assist.json --record-overlay --out output/assist/v7147_baseline
```

Run experiment B:

```powershell
python -m src.live --config config.json --live-config output/analysis_v7147/ab_configs/experiment_60ms_earlier.json --geometry config/geometry_live_assist.json --record-overlay --out output/assist/v7147_experiment
```

Input remains manually armed with `Ctrl+Shift+Alt+Q`; Esc/F12 remains the
emergency stop. Do not run both at once. Use the same song segment, window and
machine settings; A → B → B → A is preferred.


per group can produce SLOW/MISS/FAST rates. Otherwise the result remains
`INSUFFICIENT_GROUND_TRUTH`; key-down, FIRED and Combo are internal/user
observations, not automatic hit labels.

The first A/B pair is now available and was compared:

- Baseline: `output/assist/v7147_baseline/run_20261103T054928_927271Z`
  (`allow_earlier_amend=false`, 8,681 processed frames, 186 Tap key-downs,
  347 amendments: 0 earlier / 347 later).

  (`allow_earlier_amend=true`, 8,142 processed frames, 183 Tap key-downs,
  1,722 amendments: 779 earlier / 943 later).

The runs have different processed-frame counts and **zero manually labelled
game grades**, so the comparison status remains
`INSUFFICIENT_GROUND_TRUTH`. The 779 earlier amendments confirm that the
experiment switch changes the internal deadline path; they do not prove fewer
SLOW/MISS results or higher Combo. Hold counts and safety status remain
diagnostic-only.

Both runs now also contain `tap_game_grade_review.csv` with all rows marked
`UNKNOWN`, plus key-down frame probes: baseline 186 review rows / 505 frame
probes; experiment 183 review rows / 489 frame probes.

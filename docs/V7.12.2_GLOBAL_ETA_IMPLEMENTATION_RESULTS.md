# V7.12.2 / V7.13 Global Fixed-Speed ETA 實作結果

日期：2026-11-02

## 結論

已完成全域固定速度 ETA 的最小導入。它現在是普通 Tap 的獨立 Shadow 計算路徑，會以多個已確認、仍有實際觀測的 Tap 軌跡建立 bounded robust-median 速度模型，並為每個 track 保留自己的最後觀測 timestamp、位置、ETA 與 hit_at。

目前真實輸入仍由 Legacy + Particle Filter 路徑處理；`global_tap_timing.mode=shadow` 且 `allow_active=false`，所以全域模型不會送出按鍵，也不會改變 PF、Hold、Scheduler 或安全停止條件。

## 修改檔案

- `src/global_tap_timing.py`
  - 新增 `GlobalTapTimingEstimator`、`GlobalTapModel`、`GlobalTapEta`。
  - 使用多個獨立 track 的實際觀測速度中位數與 MAD。
  - 有限歷史、速度／跳點／觀測年齡／ETA horizon／不確定度限制。
  - 遮擋、coasting、舊觀測、非數值資料、非 Tap、非 PLAYING 或速度變化過大時回傳 `NOT_READY`，不產生精確假 ETA。
  - `hit_at = last_observation_timestamp + eta`；不以處理完成時間重新起算 ETA。
- `src/tap_planner.py`
  - 新增獨立 `global_plan` 與 `GlobalTapDecision`。
  - Shadow 不改 scheduler 狀態；仍套用普通 Tap、合法鍵、lane、未來時間、horizon、Hold／同鍵衝突等既有安全檢查。
  - Active 只有在 `mode=active` 且 `allow_active=true` 時才可替換提案；若全域 ETA 無效，只保留原本已通過 PF/Legacy 的提案。
- `src/simple_core.py`
  - 每幀更新共用 timing model，但維持每個 track 自己的 identity、歷史、候選鍵與 PF。
  - 產生 bounded `global_tap_timing_shadow.csv` 診斷列；不使用 lifecycle fingerprint 才記錄。
- `src/live_engine.py`
  - 傳遞 `global_tap_timing` 設定至 Simple Core。
- `src/live.py`
  - 新增 `global_tap_timing_shadow.csv` 輸出及欄位。
- `config/live_assist.json`
  - 新增：
    - `enabled: true`
    - `mode: "shadow"`
    - `allow_active: false`
    - bounded track/history、速度、跳點、horizon、不確定度設定。
- `tests/test_global_tap_timing.py`
  - 新增共享模型、非規則 FPS／timestamp、dropout/stale、coasting、ID 狀態、非數值、跳點、非線性速度、非 PLAYING 與 Active 雙開關測試。
- `tests/test_simple_core.py`
  - 新增 Shadow 不送鍵、Hold reservation 安全與 per-track global ETA 診斷測試。

## 回退與操作

- 保持目前設定即可：全域 ETA 只在 Shadow，Legacy/PF 是唯一實際輸入路徑。
- 若要暫停診斷，將 `global_tap_timing.enabled` 設為 `false`；不影響既有 Tap/Hold。
- 不應只改 `mode=active`。任何 Active 實驗必須同時明確設定 `mode=active` 與 `allow_active=true`，並先用 MockActuator／paired replay 驗證；本次未啟用。
- 沒有遊戲判定標註時，所有準確率與 Perfect/Miss 結論均為 `UNKNOWN`。

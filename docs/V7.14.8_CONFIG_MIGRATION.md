# V7.14.8 configuration migration

`src.assist_defaults.builtin_defaults()` is now the source-first baseline.
`src.assist_profiles` applies the one intentional profile variable, and
`src.assist_config.resolve_config()` performs the nested merge, validation,
provenance and fingerprinting.

| Area | Previous source | Source-first value | Override | Reason |
|---|---|---|---|---|
| Key map | `config.json` | `S,D,F,J,K,L` | rejected if changed | verified legal keys and Hold reservations |
| Capture | both JSON files | 120 FPS target, 60ms max frame age | explicit only, fail-closed | preserve stale-frame safety |
| Detector | `config.json.detector` | full detector/pink/association defaults | explicit nested merge | preserve appearance gates |
| Tracker | `config.json.tracker` | full confirmation, gap, jitter and pink defaults | explicit nested merge | preserve continuity gates |
| Particle predictor | `config.json.predictor` | full particle configuration | explicit nested merge | PF remains tracking-only |
| Global Tap ETA | `config/live_assist.json.global_tap_timing` | physical-calibrated, 4 segments, 60ms lead | explicit nested merge | retain current active Tap path |
| Deadline amendment | `config/live_assist.json.tap_deadline_amend` | freeze 30ms, step 40ms, total 80ms | earlier flag only for profile | safe A/B variable |
| Hold | `config/live_assist.json.hold_visual` | visible-tail rule and release limits | explicit nested merge | Hold path is unchanged |
| Gameplay/events | both JSON files | full existing gates and horizons | explicit nested merge | no hidden fallback |
| Geometry | `config/geometry_live_assist.json` | remains external | required `--geometry` | pending calibration and display-dependent coordinates |

The legacy `playfield.hit_y=352` remains only as a compatibility value. Live
Assist continues to use the externally loaded geometry (currently recorded as
physical y=325.5); it is not replaced by 352.

`live_run.json` now records `profile_name`, `defaults_version`,
`effective_config`, `effective_config_sha256`, `config_source`, geometry hash,
lead and earlier-amend value. Diagnostic labels are generated from the actual
numeric lead.

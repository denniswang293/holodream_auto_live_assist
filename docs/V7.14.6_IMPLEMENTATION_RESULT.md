# V7.14.6 implementation result

## Changes

- Added `tools/analyze_tap_geometry_eta.py`, a single-run, shadow-only replay
  tool. It reads the recorded identity, global ETA, intent, input and video
  index CSVs; tolerates missing files; compares top/center/bottom anchors,
  y offsets ±5/10/15/20 px and leads 0/30/50/60/70 ms; and writes per-UID and
  hypothesis CSVs without changing the active path.
- Added a non-destructive `tap_game_grade_review.csv` generator. Existing
  manual values are preserved; new rows are `UNKNOWN` / `NEEDS_GROUND_TRUTH`.
  With the provided source video it also created ±300 ms frame probes under
  `tap_geometry_review_frames/` and an index CSV.
- Corrected the baseline `config/live_assist.json` labels and added a runtime
  guard so every new run derives its label from numeric `input_lead_ms`. The
  A/B preparation helper now accepts the plan's 0/30/50/60/70 ms shadow values
  and uses `timing-lead-{N}ms` labels.
- Added unit tests for anchor-specific crossing, variable capture intervals,
  and bounded extrapolation.
- Updated only the diagnostic labels in `config/live_assist.json` from the
  stale `lead-10ms` text to `timing-lead-60ms`; the numeric lead remains 60 ms.
